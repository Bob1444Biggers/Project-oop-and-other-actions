# (Условный)Интернет-магазин (проект по ООП)

Учебный проект на Python, в котором я строю внутреннюю логику для интернет-магазина с помощью объектно-ориентированного программирования.

## Что уже сделано
* **Товары (`Product`):** создал класс для описания карточек товаров — с названием, описанием, ценой и остатком на складе.
* **Категории (`Category`):** добавил класс для группировки товаров по разделам (например, смартфоны или телевизоры). Он сам ведёт общий подсчёт всех созданных категорий и добавленных в них товаров.
* **Загрузка данных из JSON:** написал функцию, которая читает файл с готовым каталогом и автоматически превращает записи из него в объекты категорий и товаров.
* **Тесты:** покрыл код автотестами на `pytest`, чтобы убедиться, что товары создаются корректно, а счётчики не сбиваются.

## Как запустить
1. Запустить пример работы классов: `python main.py`
2. Прогнать тесты: `pytest`
